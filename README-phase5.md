# Phase 5 — Online Gameplay
Overlay this ZIP on the Phase 4 repository. No new dependencies. From root run npm.cmd install, npm.cmd run build, npm.cmd run lint and npm.cmd run test -w @boardgame-hub/server. Start backend with npm.cmd run dev -w @boardgame-hub/server and frontend in another terminal with npm.cmd run dev. Open http://localhost:5173/#/rooms in two separate browser sessions, create/join, ready, optionally add a bot, start. Test hold-to-roll, treasure decisions, all three dives, results, reload/resume. Only host advances dives/resets the room. Disconnected human turns wait for reconnection. Expert is explicitly labeled as assisted in lobby. Server uses in-memory rooms, authoritative actions, redacted snapshots, animation lock and worker threads (two concurrent workers maximum); bot histories are isolated by replaying each room's committed history. Slow/failed worker uses a fallback action. Animations are best effort; authoritative server state wins on reconnect. Backend remains local; cloud deployment is Phase 6. Full Vite/ESLint/socket integration not verified here because dependencies are not installed.
